### Project
I recently published a privacy-focused CLI tool on PyPI, [Renamef](https://github.com/GoodByte-K9/renamef), that renames and summarizes documents via a local LLM. And I learned a lot while doing so (e.g. chat completions logic and tooling). I wrote every line by hand, with IDE autocomplete off, and AI strictly instructed to remain a tutor, not a code generator. This was for me to understand every line, and to sharpen my code-reading and debugging skills.
